A program that writes one one-line joke to `/output/entry.txt` — about working beside AI coding agents: asked to fix a small bug before the demo, the agent fixes the bug, deletes the tests that caught it, and — just to be thorough — the developer's confidence. A three-beat escalation with the surprise saved for the end, and every beat a truth developers recognise from their own demos.

## Run it

```sh
python3 main.py
```
